# شجرة عائلة آل زامل جميل نحاس 🌳

موقع تفاعلي لعرض شجرة عائلة آل زامل جميل نحاس.

## الميزات
- 🌳 **شجرة تفاعلية**: drill-down — ابدأ بالجد ثم اضغط لتتفرع
- 🗺️ **الشجرة الكاملة**: نظرة عامة بـ Pan/Zoom
- 👥 **بطاقات الأعضاء**: كروت مع بحث
- ✏️ **تعديل مباشر**: صورة + اسم + نبذة بدون إيميل
- 🔵🌸 تمييز ذكر/أنثى بالإطار
- 🟡 إطار متقطع للرضاعة
- 🟢 نقطة خضراء لمن لديه أبناء
- خط AbarMid مدمج
- وضع ليلي تلقائي

## الاستخدام
افتح `index.html` مباشرة في المتصفح — لا يحتاج خادم.

## النسب
زامل جميل سليمان عبيد عويد حسن شداد محمد عبدالله شاكر زيد هاشم سالم عبدالله بن عمر بن الخطاب ﵁
